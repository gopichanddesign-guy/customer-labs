# Customer Labs landing page

Plain HTML/CSS/JS build of the Figma "Prototype" section (node 108-2347): desktop landing page, mobile layout, Book a Demo form and Demo booked confirmation.

- `index.html`: page markup and the demo modal
- `styles.css`: all styles, responsive breakpoints at 1024px and 760px
- `script.js`: opens the modal, validates the form, shows the confirmation, builds the Google Calendar link
- `assets/`: images rendered from the Figma file at 1x

Run locally: open `index.html` in a browser, or `python3 -m http.server` in this folder.

Live site: https://gopichanddesign-guy.github.io/customer-labs/
